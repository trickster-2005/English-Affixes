英文字根大全（拉丁語與希臘語字根）

本檔是《英文詞綴主題大全》的姊妹篇。詞綴（字首、字尾）附著在字根上，字根才是單字意義的核心。 想再往上追溯到所有歐洲語言的共同祖先，請看第三篇《印歐語根與同源字》。 例如 in-spect-ion = 向內 + 看 + 名詞 → 檢查；pre-dict-able = 預先 + 說 + 可……的 → 可預測的。

  • 每個字根包含：
  • 字根的各種拼法：拉丁動詞通常有兩個形態，一個來自現在式，一個來自過去分詞。例如 specere / spectus → spec / spect，所以同時有 species 和 inspect。
  • 詞源說明：一兩句，必要時附上英語本土的同源字（例如拉丁 ped- 對應英語 foot、cord- 對應 heart），讓你看到英語「拉丁借字」和「日耳曼本土字」其實是遠親。
  • 7 到 13 個常用單字，附美式 IPA 音標、中文意義與構詞拆解。

  • 經法語進入英語的字常會變形：capere → receive、tenere → maintain、tractare → treat。
  • 字首會隨字根第一個字母同化：ad + tract → attract、con + lect → collect、sub + port → support（規則詳見詞綴檔附錄 A）。

phor / pher 攜帶

詞源：希臘語 pherein「攜帶」，與拉丁語 ferre、英語 bear 同源。metaphor（隱喻）字面是「轉移、搬過去」——今天希臘的搬家卡車上還寫著 metaphora。
