# 英文字根大全（拉丁語與希臘語字根）

> 本檔是《英文詞綴主題大全》的姊妹篇。詞綴（字首、字尾）附著在字根上，字根才是單字意義的核心。
> 想再往上追溯到所有歐洲語言的共同祖先，請看第三篇《印歐語根與同源字》。
> 例如 *in-spect-ion* = 向內 + 看 + 名詞 → 檢查；*pre-dict-able* = 預先 + 說 + 可……的 → 可預測的。

---

## 使用說明

- **收錄範圍**：約 110 個最常見的拉丁語與希臘語字根，依意義分成 12 類。詞綴檔已經收錄的組合形式（如 bio-、-logy、graph-）不重複列出，對照表放在文末。
- **每個字根包含**：
  - 字根的各種拼法：拉丁動詞通常有兩個形態，一個來自現在式，一個來自過去分詞。例如 *specere* / *spectus* → `spec` / `spect`，所以同時有 *spec*ies 和 in*spect*。
  - 詞源說明：一兩句，必要時附上**英語本土的同源字**（例如拉丁 *ped-* 對應英語 *foot*、*cord-* 對應 *heart*），讓你看到英語「拉丁借字」和「日耳曼本土字」其實是遠親。
  - 7 到 13 個常用單字，附美式 IPA 音標、中文意義與構詞拆解。
- **拼法變化的線索**：
  - 經法語進入英語的字常會變形：*capere* → receive、*tenere* → maintain、*tractare* → treat。
  - 字首會隨字根第一個字母同化：ad + tract → **at**tract、con + lect → **col**lect、sub + port → **sup**port（規則詳見詞綴檔附錄 A）。
- 音標符號說明與詞綴檔相同，請見《英文詞綴主題大全》開頭的使用說明。

## 十二、希臘語字根

大部分希臘語字根在詞綴檔裡已經以「組合形式」出現（如 *bio-*、*-logy*、*graph-*），這裡收錄的是詞綴檔沒有收、但非常常見的希臘語動詞字根。

### `crit` / `cri` 判斷、分辨
> 詞源：希臘語 *krinein*「分開、判斷」。*crisis* 原指疾病的「轉捩點」——醫生在此判斷病人會好轉或惡化。

| 單字 | 音標 | 中文 | 拆解 |
| --- | --- | --- | --- |
| critic | /ˈkrɪtɪk/ | 評論家 | crit + ic |
| criticism | /ˈkrɪtɪˌsɪzəm/ | 批評 | critic + ism |
| critique | /krəˈtik/ | 評論 | 法語 critique |
| criterion | /kraɪˈtɪriən/ | 標準（複數 criteria） | crit + erion |
| crisis | /ˈkraɪsəs/ | 危機 | 希臘 krisis |
| hypocrite | /ˈhɪpəˌkrɪt/ | 偽君子 | hypo + crite |
| diacritic | /ˌdaɪəˈkrɪtək/ | 變音符號 | dia + critic |
| endocrine | /ˈɛndoʊˌkraɪn/ | 內分泌的 | endo + crine（分泌） |
| criticize | /ˈkrɪtɪˌsaɪz/ | 批評 | critic + ize |

### `dox` / `dog` 意見、教條
> 詞源：希臘語 *doxa*「意見、榮耀」與 *dogma*「信條」，皆源自 *dokein*「認為、看似」。

| 單字 | 音標 | 中文 | 拆解 |
| --- | --- | --- | --- |
| orthodox | /ˈɔrθəˌdɑks/ | 正統的 | ortho（正）+ dox |
| unorthodox | /ʌnˈɔrθəˌdɑks/ | 非正統的 | un + orthodox |
| heterodox | /ˈhɛtərəˌdɑks/ | 異端的 | hetero（異）+ dox |
| paradox | /ˈpɛrəˌdɑks/ | 悖論（違反常見意見） | para + dox |
| doxology | /dɑkˈsɑlədʒi/ | 讚美詩 | doxo（榮耀）+ logy |
| dogma | /ˈdɑgmə/ | 教條 | 希臘原字 |
| dogmatic | /dɑgˈmætɪk/ | 教條主義的 | dogmat + ic |
| orthodoxy | /ˈɔrθəˌdɑksi/ | 正統 | ortho + doxy |
| paradoxical | /ˌpɛrəˈdɑksɪkəl/ | 矛盾的 | para + dox + ical |

### `the` / `thes` 放置
> 詞源：希臘語 *tithenai*「放置」，名詞 *thesis*「放置、命題」。拉丁系對應為 *pon / pos*（第四節）。

| 單字 | 音標 | 中文 | 拆解 |
| --- | --- | --- | --- |
| thesis | /ˈθisəs/ | 論文；論點 | 希臘原字 |
| hypothesis | /haɪˈpɑθəsəs/ | 假說（放在下面） | hypo + thesis |
| synthesis | /ˈsɪnθəsəs/ | 綜合；合成 | syn（一起）+ thesis |
| antithesis | /ænˈtɪθəsəs/ | 對立；對比 | anti + thesis |
| parenthesis | /pəˈrɛnθəsɪs/ | 括號（插入旁邊） | par + en + thesis |
| prosthesis | /prɑsˈθisɪs/ | 義肢（添加物） | pros（附加）+ thesis |
| theme | /θim/ | 主題 | 希臘 thema |
| epithet | /ˈɛpəˌθɛt/ | 稱號；綽號 | epi + thet |
| synthetic | /sɪnˈθɛtɪk/ | 合成的 | syn + thet + ic |
| thematic | /θiˈmætɪk/ | 主題的 | them + atic |

### `ball` / `bol` / `blem` 投擲
> 詞源：希臘語 *ballein*「丟、投」。*devil*（魔鬼）來自 *diabolos*「誹謗者」（dia + ballein「丟過去＝中傷」）；*parliament* 也經法語 *parler*「說話」追溯到 *parabola*。

| hyperbole | /haɪˈpɝbəˌli/ | 誇飾法（丟過頭） | hyper + bole |
| metabolism | /məˈtæbəˌlɪzəm/ | 新陳代謝 | meta（改變）+ bol + ism |
| parabola | /pəˈræbələ/ | 拋物線 | para + bola |
| ballistic | /bəˈlɪstɪk/ | 彈道的；暴怒的 | ball + istic |
| devil | /ˈdɛvəl/ | 魔鬼 | 經拉丁 ← diabolos |
| problematic | /ˌprɑbləˈmætɪk/ | 有問題的 | problem + atic |
| symbolic | /sɪmˈbɑlɪk/ | 象徵性的 | sym + bol + ic |
| metabolic | /ˌmɛtəˈbɑlɪk/ | 代謝的 | meta + bol + ic |
| symbolism | /ˈsɪmbəˌlɪzəm/ | 象徵主義 | sym + bol + ism |

### `phor` / `pher` 攜帶
> 詞源：希臘語 *pherein*「攜帶」，與拉丁語 *ferre*、英語 *bear* 同源。*metaphor*（隱喻）字面是「轉移、搬過去」——今天希臘的搬家卡車上還寫著 *metaphora*。

| pheromone | /ˈfɛrəˌmoʊn/ | 費洛蒙 | phero + mone（激發） |
| peripheral | /pəˈrɪfərəl/ | 周邊的 | peri + pher + al |
